# 十课 × 练习仓库 对照表

说明每一课用到仓库的哪些部分。发布议题的时机由教师控制，
不要提前发布后续课次的议题文件。

| 课次 | 用到仓库的什么 | 关键动作 |
|---|---|---|
| 第 2 课 安全部署 | 仓库本身 + `docs/SAFE-USE.md` | 配置专用身份与最短授权，验证访问边界 |
| 第 3 课 领域模型 | Issues 与评论作为事件来源 | 理解 Source / Trigger / Thread 对应到真实 GitHub 对象 |
| 第 4 课 研发闭环 | 议题 01（list 空列表崩溃） | 显式 @ 授权 → 工单 → 独立执行 → PR |
| 第 5 课 交付规范 | 议题 01 的 PR | 对照五类交付信息改造 PR 内容 |
| 第 6 课 持久化恢复 | 修复任务执行中 | 正常重启 + 原议题追问续作 |
| 第 7 课 控制面 | 面板中的工单与记录 | 并发/排队、停止/重试/暂停、找证据 |
| 第 8 课 主动事件 | `scripts/trigger-ci-failure.sh` | CI 失败事件 → 观察模式候选；演示后运行 restore 脚本 |
| 第 9 课 结课项目 | 议题 02（done 编号不存在） | 全新议题从零到 PR + 四项证据回归 |
| 第 10 课 验收答辩 | 全部证据链 | 现场抽点定位证据 |
| 第 1 课 概念 | 无需操作仓库 | 讲师可现场演示一次 add/list |

## 教师发布节奏

1. 开课前：推送本仓库到私有 GitHub 仓库，配置专用账号与 CI
2. 第 3 课前：发布议题 01
3. 第 8 课前：确认 CI 演示脚本可运行（不需要提前发布议题 03）
4. 第 9 课前：发布议题 02
