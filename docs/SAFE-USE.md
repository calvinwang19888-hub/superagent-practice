# 练习仓库安全使用约定

本仓库是课堂练习专用仓库。接入 Super Agent（或任何自动化智能体）前，请全体学员阅读本文件。

## 必须遵守

1. **专用身份**：智能体使用教师发放的专用账号或细粒度令牌，不使用任何人的个人账号。
2. **最短授权**：令牌只授予本仓库的 Issues、Pull requests、Contents 读写权限；不给组织级权限。
3. **人工评审**：所有 PR 停在"等待评审"状态，**任何情况下不开启自动合并**。
4. **观察模式**：第 8 课的主动规则全程保持 `observe`，只记录评估，不自动接单。
5. **记录在案**：未授权事件被拦截的记录、观察候选的评估记录都要保存，进入结课证据链。

## 明确禁止

- 把个人或公司生产仓库配置为事件来源
- 在议题、评论中粘贴任何真实凭据（令牌、密码、密钥）
- 为了"让 CI 变绿"跳过测试或改断言
- 使用 `danger-full-access` 模式执行任务

## 数据说明

- 仓库中的任务数据保存在 `.todo.json`，属于课堂示例数据，可以随时删除重建
- CI 只运行标准库测试，不安装第三方依赖，不出网
